# Requesting ULEAD Access

Researchers and study team members can request ULEAD access through the UCLA Health Data Governance Portal.

Access requests must be submitted at the **most granular level**:

- **One request per user**
- **One request per IRB protocol**

If a user needs access under multiple IRB protocols, a separate request must be submitted for each IRB.

## Access Request Process

1. Go to the [UCLA Health Data Governance Portal](https://uclahealth.collibra.com).

2. Sign in using your **Mednet Active Directory (AD) credentials**.

3. Select **ULEAD Access Request**.

4. Complete the access request form.

5. For an IRB study, include the following information:

   - **IRB number**
   - **Principal Investigator (PI) name**
   - **CTSI consultant name**, if applicable
   - **Project title**
   - **Justification for access**

6. Submit the request.

7. After submission:

   - The provisioning workflow will begin.
   - A ServiceNow ticket will be created.
   - The request will proceed through the required review and approval process.

## Important Requirements

### Access Is User-Specific

ULEAD access is granted at the individual-user level. Each study team member who needs access must submit a separate request.

Users must not share accounts or use another team member's access.

### Access Is IRB-Specific

ULEAD access is associated with a specific IRB protocol. Access approved under one IRB does not provide access under another IRB.

If a user works on multiple IRB-approved studies, the user must submit a separate access request for each IRB.

## Before Submitting

Confirm that:

- The user has active Mednet AD credentials.
- The correct IRB number is included.
- The PI and project information match the IRB study.
- The justification clearly explains why the user needs ULEAD access for the study.
- A separate request has been prepared for each user and IRB combination.

## Questions or Technical Issues

If you are working with CTSI Data & Informatics Services and are unsure whether ULEAD is appropriate for your project, consult your CTSI analyst or consultant before submitting the request.

For technical problems with an existing ULEAD account, follow the separate **ULEAD Access Issues – Escalation Process**.
