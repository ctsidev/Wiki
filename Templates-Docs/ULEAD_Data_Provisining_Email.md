Many users attempt to open the folder with Excel and report that the dataset files are missing.
In most cases, the files are present and the issue is caused by the file-type filter.
When opening the folder, change the file filter from:

```text
Excel Files
```

to:

```text
All Files
```

This will allow all dataset files to appear.
